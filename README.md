Real time pothole detection using YOLOv8  trained on custom dataset  deployed on Hugging Face
# YOLOv8 Pothole Detection

Custom trained YOLOv8 model for real time 
pothole detection on road images.

## Results
Training images: 1363
Epochs: 25
mAP50: 65%
Best confidence: 80%

## Model
Trained on custom pothole dataset from Roboflow
Base model: YOLOv8n
Framework: Ultralytics
